# Всё о человеке — одной командой

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes person`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed person 2>/dev/null || rodo skill-notes --embed person 2>/dev/null || true`

**Что это.** Два шага. Сначала — короткий ответ `tree.py` (до 20 строк, меньше секунды): кто он, родня, на чём
держатся факты, где упомянут. Часто этого хватает — карточку и биографию целиком тогда не читать. Нужно всё сразу
(глава, разговор о человеке) — досье `person_dossier.py`: карточка встраиванием, упоминания во всём проекте с цитатой
строки, что о человеке уже написано в книгах и чего там ещё нет. Obsidian ни для одного не нужен.

```bash
rodo tree who "Евлампий Ласточкин"          # годы, места, родня, факты по происхождению, биография
rodo tree kin "<Я>" "Евлампий Ласточкин"     # кем приходится и через кого
rodo tree mentions "Евлампий Ласточкин"     # в каких файлах упомянут (кэш — tools/.cache)
rodo tree find Ласточкин                    # все Ласточкины во всех написаниях (Lastochkin, Ласточкен…)
rodo tree gaps "Евлампий Ласточкин"         # чего не хватает
rodo person-dossier "Евлампий Ласточкин" --stdout   # всё целиком (→ без --stdout: 3_research/_dossiers/)
rodo person-dossier --line Ласточкин         # вся ветка (кровь, поле lineage)
rodo update-all --dossiers                   # досье всех прямых предков
```

Имя — как называется карточка в `3_research/tree/people/`, или cr_id, или номер MyHeritage (вида I123). Не знаешь
точно — `tree.py find <фамилия>` покажет всех во всех написаниях.

## Как пользоваться результатом

1. **Сначала `tree.py who`**; не хватило — досье целиком (`--stdout`), а не карточку и биографию по отдельности.
2. Отвечая пользователю: кто он → что известно и на чём держится (семья / найдено / чужое дерево) →
   расхождения → чего не хватает → что уже в книге.
3. Раздел «**В книгах, похоже, ещё нет**» — подсказка по ключевым словам и годам. Перед вставкой в книгу
   сверить глазами (скилл `book-chapter`).
4. Нашёлся новый факт — вносить **в карточку**, не в досье: досье пересобирается и в git не хранится.
5. **Возможные связи** — `tree.py who` показывает «возможно, тот же / брат…» и «проверено — нет» с обеих сторон.
   Новое подозрение — полем `maybe_same` / `maybe_kin` (+ `_id`) в карточке найденного человека и строкой со ссылкой в
   его «Открытых вопросах», а не фразой «возможно, это наш …» в тексте; отвергли — `possible.py no` (`not_same`/`not_kin`).

## Чтобы человек находился в книгах

Сборщик ищет по имени карточки, `aliases` и **домашним именам** — поле `home_names` в карточке
(«дед Лампа», «Евлаша», «баба Улита»; падежи ловятся сами). Если в книге человек назван иначе — дописать
форму в `home_names`.
