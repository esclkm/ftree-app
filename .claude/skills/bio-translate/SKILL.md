# Перевод биографий — по запросу

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes bio-translate`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed bio-translate 2>/dev/null || rodo skill-notes --embed bio-translate 2>/dev/null || true`

**Что это.** Биографии пишутся по-русски, русский — основной язык. Перевод делается, только когда о нём
попросили (для родни, которая читает на другом языке).

## Где лежат переводы — одна схема на всё

Один переводимый объект — один файл, названный как оригинал (`paths.tr_path`):

```
3_research/tree/translations/
  00_АВТОПЕРЕВОД.md                        кого переводить, словари имён и слов, имена в шапке
  <es|pl|en>/biographies/<Имя карточки>.md биография (bio_translation.py, bio_autotranslate.py)
  <es|pl|en>/places/<Имя карточки>.md      текст карточки места и дома       ┐
  <es|pl|en>/facts/<Имя карточки>.md       блок «Факты» человека              ├ tr_texts.py, устройство — tr_store.py
  <es|pl|en>/photos/<имя файла фото>.md    подпись снимка из описи            ┘
```

Шапка у всех одна: `kind`, `of` (что переводим), `of_id` (номер карточки; у фото — имя файла), `lang`,
`source_hash` (отпечаток русского — по нему «перевод отстаёт»), `translated`, `method: ИИ`, `model`, `reviewed`.
Места: «О месте» — под заголовком языка (`## Sobre el lugar`), «Государства по годам» не переводим (их переводит
`ERA_TR`). Факты: раздел `## <отпечаток строки>` и поля `label:` `text:` `reasoning:` `locators:` — строку поправили,
и сайт показывает её по-русски, пока не переведут. Фото: разделы `## desc` `## whose` `## exact` `## note`
`## section`; переводятся только при неизменной русской подписи. Описи `00_ОПИСЬ*.md` не трогаем.

```bash
rodo tr-texts status --lang es --person "Иван Ткачук"      # что пора перевести
rodo tr-texts translate --lang es --person "…" --person "…"          # факты, места, фото их страниц
rodo bio-autotranslate --lang es --model sonnet --full --only "…"    # биография заново целиком
```

Тот же перевод можно пустить через GitHub Copilot: у него свой лимит, подписку Claude это не тратит. Команда —
`--model copilot:claude-haiku-4.5`, модель та же Haiku. Есть ещё `copilot:claude-sonnet-5.5` и
`copilot:gemini-3.8-flash` (подробно — навык `orchestration`, раздел о Copilot). Кто перевёл, пишется в шапку
перевода.

Модель — Haiku; **Sonnet — только по просьбе владельца дерева** (`--model sonnet`). Сайт (`site_export.py`) сам показывает
перевод на языке читателя, а если его нет — русский текст с подсказкой «нажмите „Перевести“ в браузере».

```bash
rodo bio-translation source "Иван Ткачук"          # русский текст + номер + имена
rodo bio-translation write "Иван Ткачук" --lang es \
        --name "Juan (Iván) Tkachuk" < /tmp/перевод.md                        # записать с правильной шапкой
rodo bio-translation status                                   # что переведено, что отстало
rodo bio-translation status --line Ткачуки --lang es          # кого из ветки ещё нет
rodo build-site                                               # пересобрать сайт
```

## Автоперевод — кто в списке, переводится сам

Таблица `3_research/tree/translations/00_АВТОПЕРЕВОД.md` — кого переводить без просьбы (кто — с предками
и потомками, на какие языки), словари имён и слов для каждого
языка и «## Карточки: <язык>» — имя человека в шапке перевода. `bio_autotranslate.py` находит, у кого
из них перевода нет или русский текст поменялся, и переводит через Claude (`claude -p`; нет его — API с ключом
`ANTHROPIC_API_KEY`; нет ничего — только печатает список). **Запускается сам после каждого коммита на master**
(`sync.py post-commit` из `publish_site.sh`, отдельный коммит «Автоперевод биографий»), и в `update_all.py`
(пропустить: `--no-translate`). Лог — `/tmp/ftree_<дерево>_autotranslate.log`.

**Это ИИ-перевод, не машинный.** Claude получает роль переводчика семейной книги, кто читатель (родня в какой
стране), словарь имён и словарь слов (`## Слова: es` — «примаки», «фильтрация», ЗАГС…) и прежний
перевод как образец. В шапке перевода — `model:` (кто переводил).

⭐ **Дёшево и по частям:** модель — **Claude Haiku 4.5**. Текст режется по заголовкам,
в шапке перевода — `section_hashes` (отпечатки русских разделов). Поменялся один раздел — **заново переводится
только он**, остальные берутся из прежнего перевода как есть. Целиком — только первый перевод. Переводя вручную
в сессии, делать так же: только изменённые разделы, через `bio_translation.py write … --sections "<отпечатки>"`.
Google-переводчик и т. п. не использовать никогда; кнопка «Перевести» в браузере на сайте — только для тех, кого
в списке нет.

```bash
rodo bio-autotranslate --check   # кто отстал, ничего не переводя
rodo bio-autotranslate           # перевести отставших
```

Новый человек без строки в «## Карточки: <язык>» получит перевод без имени в шапке (сайт покажет латиницу) —
дописать строку, и следующий перевод возьмёт имя оттуда.

## Порядок

1. `source` — взять **текущий** русский текст (он собирается из разделов биографий, на которые ссылается карточка).
2. Перевести **весь** текст, ничего не сокращая и не добавляя. Цитаты родни — переводить, а в скобках оставить
   ссылку на источник как есть: *(Аудио 02, 13:48)*. Пометки уверенности (⭐, ⚠️, 🟡) — сохранить.
   Ссылки `[[…]]` не переводить и не ломать — сайт превращает их в ссылки на людей и места.
3. `write` — **только через скрипт**: он ставит `person_id` и «отпечаток» русского текста. Руками шапку не писать.
4. Пересобрать сайт, открыть страницу человека на этом языке и проверить.

## Имена на языке перевода (`--name`)

- **Испанский:** как в прежних переводах и в словаре имён `00_АВТОПЕРЕВОД.md` — так родня знает этих людей
  (например, Iván → Juan). Нет в словаре — не
  выдумывать испанское имя, оставить `--name` пустым (сайт покажет латиницу Ivan / Prokhor).
- **Польский:** как в польском словаре имён; нет там — польская транслитерация по умолчанию (Wasilij, Jefim).
- Фамилии не «переводить»: Tkachuk, Tkaczuk — как в дереве.

## Правила

- Перевод помечен `method: ИИ`, `reviewed: false` — на сайте видно «перевод ИИ, не проверен». `reviewed: true`
  ставится, только когда перевод прочитал носитель языка (кто-то из родни, кто читает на этом языке) и сказал об этом.
- Русскую биографию поправили → `status` покажет «отстаёт от русского», на сайте — жёлтая пометка. Обновить:
  снова `source` → перевод → `write` (файл перезапишется, `reviewed` вернётся в `false`).
- Не переводить заранее «всё подряд» — только то, что попросили.
- Разделы, которые сайт вынимает из текста, называть **ровно так**, иначе на сайте они останутся куском текста:
  «Линия жизни» — `Linia życia` / `Línea de vida` / `Timeline`; «Память» — `Pamięć` / `Memoria` / `Remembrance`;
  «Воспоминания» — `Wspomnienia` / `Recuerdos` / `Memories`, строка под каждой сценой — `*Wspomina …*` /
  `*Recuerda …*` / `*Remembers …*`, сцен столько же и в том же порядке, что в русском.
