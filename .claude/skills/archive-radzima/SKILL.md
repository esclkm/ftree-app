## Что это и когда

radzima.net — сайт-справочник «найди свои корни в Беларуси и Литве». Это **не архив**: документов там нет. Там есть страница на каждую деревню, церковь и костёл. На страницах церквей (при оплаченном Premium) видно три вещи:
1. список селений, которые ходили в эту церковь (приход);
2. какие метрические книги (записи о рождениях, браках, смертях) сохранились: годы, архив, фонд, опись, дело;
3. ссылки на сканы этих книг на FamilySearch, если они там есть.

Зачем: сайт отвечает на вопрос «в какую церковь ходила деревня Заречье и в каком архиве лежит её книга». Сам ответ сайта — подсказка, куда писать или смотреть. Доказательство — запись в самой книге.

Что уже смотрели — в заметках дерева (`rodo skill-notes archive-radzima`) и в источнике radzima в `3_research/tree/sources/`. Сначала загляни туда.

## Пошагово для исполнителя (читай первым)

### Свой Chrome — главный способ (с 02.10.2026, задача B1) [П]

Отдельный Chrome с профилем `$ARCHIVES_LOCAL/browser-profile` (вне проекта, git и облака). Владелец дерева вошёл в нём
один раз, Chrome сам хранит вход и пароли; вход пережил два перезапуска Chrome подряд [П 02.10]. Управляет скрипт, не
модель: в разговор приходит только итог. Панель браузера приложения — только чтобы владелец посмотрел глазами.
Этот раздел главнее слов «в панели браузера» ниже: там — как было раньше, а признаки страниц и адреса верны и сейчас.

```bash
B="rodo browser-cdp"
$B start                      # уже запущен — ничего не сделает
$B login-check radzima        # «вошёл» → дальше; «не вошёл» — открыл вход в окне Chrome: владелец входит (пароль
                              # подставит Chrome), Claude ждёт «вошёл»; код 3 и «✋» — капча или лимит: стоп, сказать владельцу
$B nav <url>; $B text 3000    # открыть и прочитать текст (вместо navigate + get_page_text)
$B eval '<js>'                # сниппеты ниже — как есть; длинный ответ уходит в файл
$B stop                       # в конце работы: пока Chrome открыт, его порт доступен любой программе на этом Mac
```

Перезапускать Chrome без спроса нельзя: 02.10 так потеряли вход ГАСО (тогда ещё без «Продолжить с того же места» —
теперь `start` включает это в профиле сам). cookie, хранилище и пароли скрипт читать отказывается — не обходить.

Запасной путь, если свой Chrome не запускается, — встроенный браузер: `mcp__Claude_Browser__navigate`, `get_page_text`, `find`, `javascript_tool`.

**Железные правила**
- Пароль, cookie, токены у владельца дерева **не просим**. Из страницы их **не копируем** — ни в `curl`, ни в файл, ни в чат. Скачивать с radzima нечего, всё читается текстом внутри страницы (`fetch(url,{credentials:'include'})` — браузер сам подставляет вход).
- Входит **сам владелец дерева**, в своём Chrome проекта (раздел выше): там вход держится между перезапусками [П 02.10]. В панели браузера приложения он терялся (02.10 свежая панель показала заглушку Premium).
- Капча или «подтвердите, что вы не робот» → **стоп**, скажи владельцу. Не обходить.
- Ответ 403 / 429 / страница «слишком много запросов» → **стоп**, паузу ≥10 минут, спроси владельца.
- Не листай сайт подряд. Только места из «Что ищем». Паузы между страницами ≥2 с. Один вызов `javascript_tool` — не больше ~4000 знаков ответа.
- Скриншоты всего экрана — нет (в сессии 44749ad9 их было 165, это ≈ $120 из общих). Нужна картинка — масштаб 0.3 и только если текст не помогает.

**Шаги**
1. `navigate` → контрольная страница — любой православный приход со сканами (`https://www.radzima.net/ru/prihod/<slug>.html`). Затем `javascript_tool`:
```js
const t=document.body.innerText; JSON.stringify({premiumStub:/Для пользователей с Premium планом доступны/.test(t), hasFS:document.querySelectorAll('a[href*="familysearch"]').length, len:t.length})
```
   - `premiumStub:true`, `hasFS:0`, `len≈1000` → **не вошёл**. Скажи владельцу: «Открой в панели справа https://www.radzima.net/ru/login/ , войди и напиши "вошёл"». `navigate` на `/ru/login/` сделай сам, дальше **жди** его слов. Потом повтори шаг 1.
   - `premiumStub:false`, `hasFS` больше 0 (у католического прихода без сканов может быть 0 — тогда смотри `len`, он в тысячи) → вошёл, иди дальше.
2. **Найти деревню** (на её странице — приход). `navigate` → `https://www.radzima.net/ru/search_place_new/` (форма ищет **по месту**, по фамилии не ищет). Потом сниппет «sp» (ниже): `await sp('Сосновка')`. Ожидаемый ответ: строки вида `Сосновка, деревня (<сельсовет>, <район>, <область>) → /ru/miejsce/sosnowka.html`. Пусто → пиши варианты (Заречье / Зарэчча), корень слова короче.
3. **Страница места**: сниппет «place» (ниже) с адресом `/ru/miejsce/<slug>.html`. Ответ: «Административная принадлежность» по годам (1870, 1905, 1924, 1933, 2017), комментарии пользователей, в конце `PARISH: /ru/prihod/…` — православный приход и/или `/ru/parafia/…` — католический.
4. **Страница прихода**: `/ru/prihod/<slug>.html` (православные церкви) или `/ru/parafia/<slug>.html` (костёлы). Сниппет «parish» (ниже), годы подставь свои. Ответ: есть ли нужное селение в списке, число книг, строки `год — тип ЛГИА 634/4/276 ⇒ ссылка FamilySearch`.
5. Города (бывшие уездные) в «Поиске места» **не заведены** [П]: заходи через страницы приходов (`/ru/parafia/<город>-kosciol.html`) и епархий (`/ru/eparhiya/minskaja.html` — список благочиний).
6. Сохрани результат: `Write` в `1_sources/found/archives_online/radzima/` (раздел «Куда класть»). Потом строка в каталог и запись в `ПОИСК_СДЕЛАНО.md` (открытая задача — `ПОИСК_ОНЛАЙН.md`).
7. Ссылки FamilySearch из ответа читай по скиллу `archive-familysearch`, не здесь.

### Сниппеты (скопированы из сессии 30.09; секретов нет)

**sp — поиск места** (запускать на странице `/ru/search_place_new/`):
```js
window.sp = async (q) => { const fd = new URLSearchParams({name:q, form_go_place:'1'}); const h = await (await fetch('/ru/search_place_new/',{method:'POST',body:fd,credentials:'include'})).text(); const d=new DOMParser().parseFromString(h,'text/html'); return [...d.querySelectorAll('a')].filter(a=>/\/miejsce\//.test(a.getAttribute('href')||'')).map(a=>(a.closest('tr,li,div')||a).innerText.replace(/\s+/g,' ').trim().slice(0,160)+' → '+a.getAttribute('href')); };
const out={}; for (const q of ['Сосновка','Заречье']) out[q]=(await sp(q)).slice(0,15); out
```

**place — страница места** (одной строкой, до 1800 знаков):
```js
const place = async (u) => { const h=await (await fetch(u,{credentials:'include'})).text(); const d = new DOMParser().parseFromString(h,'text/html'); const m = d.querySelector('main')||d.body; m.querySelectorAll('script,style,form').forEach(e=>e.remove()); const links=[...m.querySelectorAll('a')].filter(a=>/prihod|parafia/.test(a.getAttribute('href')||'')).map(a=>a.getAttribute('href')); let t=m.innerText.split('\n').map(s=>s.trim()).filter(s=>s&&!/^\.+$/.test(s)).join(' | '); const a=t.indexOf('Административная'); const b=t.indexOf('О сайте'); return d.title+'\n'+t.slice(a>=0?a:0,b>0?b:undefined).replace(/ \| ответить/g,'').slice(0,1800)+'\nPARISH: '+links.join(' ; '); };
(await Promise.all(['/ru/miejsce/zarzecze.html','/ru/miejsce/sosnowka.html'].map(place))).join('\n\n=====\n')
```

**parish — книги прихода за нужные годы со ссылками на сканы** (собран из двух проверенных `M` и `P`; поменяй `Y0`,`Y1` и `NAME`):
```js
const Y0=1885, Y1=1895, NAME=/Сосновк/; // нужные годы и название селения
const parish = async u => { const h=await (await fetch(u,{credentials:'include'})).text(); const d=new DOMParser().parseFromString(h,'text/html'); const m=d.querySelector('main')||d.body; const t=m.innerText.replace(/\s*\n\s*/g,' | '); const vi=t.indexOf('Список селений'); const vill=vi>0?t.slice(vi,vi+1500):''; const rows=[]; m.querySelectorAll('a[href*="familysearch"]').forEach(a=>{ let el=a,txt=''; for(let i=0;i<4&&el;i++){el=el.parentElement; txt=el.innerText.replace(/\s+/g,' ').trim(); if(/\d{4}/.test(txt)) break;} const y=parseInt((txt.match(/\d{4}/)||[0])[0]); if(y>=Y0&&y<=Y1) rows.push(txt.replace(/о родившихся, бракосочетавшихся, об умерших/,'Р+Б+У').replace(/ЛГИА — Фонд (\d+), опись (\d+), дело (\d+)/,'ЛГИА $1/$2/$3').replace(/НИАБГр — Фонд (\d+), опись (\d+), дело (\d+)/,'НИАБ $1/$2/$3').slice(0,80)+' ⇒ '+a.href.replace('https://www.familysearch.org/ark:/61903/','')); }); return '#### '+u+' '+d.title.slice(0,70)+'\nселение в списке: '+NAME.test(vill)+'\nСКАНОВ в годах: '+rows.length+'\n'+rows.slice(0,40).join('\n'); };
(await Promise.all(['/ru/prihod/<slug>.html'].map(parish))).join('\n\n')
```
Ожидаемый ответ: заголовок, `селение в списке: true/false`, строки `1850 — Р+Б+У ф.920/1/15 ⇒ fs:…`. Если строк больше 40 — сузь годы, не печатай всё.

Если нужно **выписать весь приход целиком** (все книги и все селения, сотни строк — у большого прихода бывает за 300 книг): не выводи это в ответ. Собери текст в переменную и передай его в ответ только короткой сводкой (число книг, годы по десятилетиям); полный список нужен **один раз** — прочитай его кусками по 3000 знаков через `.slice(0,3000)`, `.slice(3000,6000)` и запиши в файл через `Write`. [П — как делали; готового «выписать всё» одним вызовом нет, тот код в логе не сохранился]

## Как читать результаты дёшево

- Первая попытка — `get_page_text` на странице прихода (текст ≈ в тысячи знаков, без картинок) [П]. Для списков с ссылками на сканы — `javascript_tool` с `fetch` (выше): ссылки видны только в разметке.
- Один вызов — одна короткая строка JSON/текста. Длинное — не в чат, а `Write` в файл сразу (раздел «Куда класть»).
- Много страниц сразу — `Promise.all([...].map(fn))` в **одном** вызове, как в сниппетах [П]. Выигрыш: 1 шаг вместо 10, а каждый шаг перечитывает весь разговор.
- Снимать экран незачем. Панель карты (`⤢`, `+ −`) — шум.
- **Фото на radzima есть, но мало** [П 01.11.2026]: у прихода — одно фото храма (`/imgs_folder/prihod|parafia/<id>/…-b1.jpg`); у деревни — памятники с radzima.org (`radzima.org/images/pamatniki/<id>/…_sm|_s1.jpg`: церковь, усадьба, мельница) и альбомы пользователей (`/imgs_folder/users/…`). Остальные `img` на странице прихода — значки микрофильмов, не фото. У многих деревень своих фото нет вовсе.

## Как сохранить без участия владельца

- **Рабочий рецепт [П]:** текст со страницы → `Write` в файл. Ни кнопок «Сохранить», ни скачивания не нужно. Владелец дерева в этом не участвует (кроме входа).
- Раньше страницы сохраняли целиком как `.html` в `1_sources/found/archives_online/radzima/` — как именно, по логам не видно [В: брали `document.documentElement.outerHTML` кусками или сохраняли руками]. Новое — только текстом: выписка с датой и адресом страницы вверху.
- Не сохраняй комментарии пользователей целиком: там имена живых людей. Нужное — одной строкой (кто, год, суть) в отчёте `findings/`.

В карточке места — ссылка на источник radzima и фраза «по справочнику приходов radzima.net»; **не** «доказано». Оговорка в источнике: это справочник, составленный сайтом.
- **Возможно, наш — полем, не текстом.** Человек из записи о нашем человеке или прямом звене получает свою карточку; боковые ветки, крёстные и поручители — строкой в отчёте или в факте записи (`card-rules`, «только у звена»). Подозреваем, что это кто-то из дерева, — в его свойства `maybe_same: "[[X]]"` + `maybe_same_id`, или `maybe_kin: "[[X]] — брат?"` + `maybe_kin_id` (кем приходится — словом с «?»); на чём держится и что докажет — строкой со ссылкой `[[X]]` в «Открытых вопросах». Обратная сторона у X появится сама. Проверили, что нет, — `rodo possible no "<карточка>" "<X>" --why "…"` (пишет `not_same`/`not_kin`, пара больше не всплывёт). Связь `father`/`spouse` — только по документу. Все пары рядом — `possible.py` → `3_research/tree/_СВЕРКА.md`. Кандидатов из дерева под запись — `tree.py find <фамилия> --for "<имя>"`: проверенные «нет» не показываются.

## Условия сайта и ограничения

- Доступ платный, личный, на владельца дерева.
