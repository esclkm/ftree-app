# Восстановление фотографии

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes photo-restore`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed photo-restore 2>/dev/null || rodo skill-notes --embed photo-restore 2>/dev/null || true`

Пайплайн: **обрезка/выпрямление → цветокоррекция → ИИ (лица + апскейл)**.
Скрипты: `tools/scripts/photo_restore.py`, окружение — `tools/setup/photo.sh`.

## 0. Один раз — поставить ИИ-окружение
```bash
bash tools/setup/photo.sh        # создаёт ~/.relatives_ai_venv + качает веса (~2 ГБ, долго)
```
Дальше всегда запускать через `~/.relatives_ai_venv/bin/python`.
Тяжёлый шаг лучше пускать в фоне (nohup) и дождаться «сторожем» (run_in_background bash, ждущим маркер в логе).

## 1. Обрезка/выпрямление (если нужно)
- **Прочитай изображение** (Read), чтобы увидеть его. Если фото снято под углом / лежит на фоне
  (стол, ноутбук, рука) — определи **4 угла самой фотографии** в пикселях ПОЛНОГО разрешения
  (учти масштаб превью Read: обычно превью шириной 768 или 1092 — умножь координаты на
  `реальная_ширина / ширина_превью`).
- Передай углы (в любом порядке) как `--corners "x1,y1;x2,y2;x3,y3;x4,y4"`.
- Либо `--auto` (контурный детект; надёжно только на контрастном фоне — на светлом часто промахивается).
- Если обрезка не нужна — не указывай ни `--corners`, ни `--auto`.
- **Проверь результат** через Read; не подрезаны ли люди по краям — при необходимости расширь углы и повтори.

## 2. Запуск
```bash
~/.relatives_ai_venv/bin/python tools/scripts/photo_restore.py \
  --in /путь/исходник.jpg \
  --out 2_transcripts/photos_processed/restored/I<ID>_NN_Имя_описание.jpg \
  --corners "60,586;184,1744;1376,1724;1324,580" \
  --engine codeformer --fidelity 0.7
# опции: --auto | --no-color | --no-ai | --engine gfpgan|codeformer | --fidelity 0..1
```
- ИИ-этап: апскейл ×2 + восстановление лиц.
- **`--engine codeformer`** (по умолчанию) — естественнее на старых/групповых фото; `--fidelity` 0..1 (выше = ближе к оригиналу, ниже = сильнее «дорисовывает»). `--engine gfpgan` — альтернатива.
- На Mac CodeFormer форсится на CPU (иначе конфликт MPS).
- **Убрать пятно/дефект (инпейнтинг):** до ИИ — маской по цвету (пятно ≠ цвет ткани, напр. `R−B`) + `cv2.inpaint`; затем обычный прогон. Не трогать содержимое сверх дефекта (фото историческое).
- Без `--corners/--auto` обрабатывается весь кадр.

## 3. Привязать к дереву
- Имя файла: `2_transcripts/photos_processed/restored/I<номер>_NN_Имя_описание.jpg` (NN — порядковый, чтобы не затирать).
  Оригинал не трогаем: он остаётся на этаже 1 (`1_sources/…`), реставрация — копия на этаже 2.
- Добавь снимок в поле `media` карточки человека (`3_research/tree/people/<Имя>.md`): `- "[[имя_файла.jpg]]"`.
  Первое фото в списке — портрет на схеме; реставрацию ставь первой, только если она лучше оригинала.
- Затем `rodo photo-catalog` — каталог `3_research/КАТАЛОГ_ФОТО.md` обновится.
- Порядок хранения фото — в `START_HERE.md`, раздел «Фото».

## Заметки
- ИИ восстанавливает то, что есть; из сильно размытого исходника чудес не будет — для максимума
  лучше пересканировать бумажный отпечаток ровно.
- Веса и venv — вне репозитория (см. `.gitignore`: `tools/ai_weights/gfpgan`, и не коммить `~/.relatives_ai_*`).
- Известный баг basicsr/torchvision (`functional_tensor`) уже обойдён шимом в `tools/setup/photo.sh`.
