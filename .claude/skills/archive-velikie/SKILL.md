# «Великія описи»: поиск по описям и указателям, снимки дел

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes archive-velikie`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed archive-velikie 2>/dev/null || rodo skill-notes --embed archive-velikie 2>/dev/null || true`

## Что это

- **inv.velikie.org** — база описей (шифр, заголовок, даты, листы) и указатели, которые набирают добровольцы.
  Вкладки выдачи: «Дела» (заголовки дел описей), «Записи» (строки указателей: например «4 1234 1901 Иван Петров … деревня
  …» — опись, дело, год, кто, у кого, откуда), «Документы», «Фонды». Поиск — **только после входа**: владелец дерева один раз
  входит в своём Chrome проекта (`browser_cdp.mjs`), вход держится.
- **f.velikie.org** — снимки складчин (`rgia-592/rgia-592-<опись>-<губерния>--<уезд>.zip`, `rgia-1290/…`). Объявления — в
  Телеграме @kpb_rgia (навык archive-telegram). Форматы: JPG или JXL.
- Каждое дело Крестьянского банка начинается с карточки фотолаборатории «ФОНД № … ОПИСЬ № … ДЕЛО № …»; первый лист —
  «Постановление … Отделения …»: кто покупает (имя, отчество, фамилия, деревня, волость), у кого, сколько земли, цена,
  задаток, ссуда, состав семьи, скот.

## Команды

```bash
rodo velikie login-check                       # вошёл ли; нет — открывает вход в окне Chrome (код 3) — позвать владельца
rodo velikie search Лесовской Заречье …           # выдачи → <found>/velikie/search/<слово>.tsv (повтор — пропускает; --force)
rodo velikie filter "Сосновк|Заречь" [слова …]     # строки сохранённых выдач по региону — отсев однофамильцев
rodo velikie zip-list <url zip> [--grep 34]    # оглавление архива по сети: папки дел и число кадров
rodo velikie zip-get <url zip> 592-4-1230_1240 <папка>   # только эти кадры (без скачивания всего архива)
rodo velikie ocr <папка>                       # Apple Vision на Mac, без токенов → <папка>/vision.jsonl
rodo velikie grep <vision.jsonl> "Лесовск|Заречь"  # где слово, с номером дела по карточкам
```

## Как работать (порядок)

1. `search` по фамилии и по деревне (без отчества; сайт сам ищет формы слова). Два слова сразу сайт не понимает — пусто.
2. `filter` по губернии/уезду/волости — однофамильцев в других краях отбросить сразу.
3. Нашлась «Запись» Крестьянского банка → номер дела (второе число: «4 1234» = опись 4, дело 1234). `zip-list --grep`
   находит папку с этим делом, `zip-get` берёт её, `ocr` + `grep` — кадры дела.
4. Читать кадры: Copilot (`rodo llm ask … --image`), при лимите — помощник (Agent sonnet). Главная сессия картинки не
   читает (хук). Вывод — в отчёт `findings/`, факт в карточку — по правилам дерева (уровень родства, «да» владельца).

## Что знать

- Счётчик «Записи (N)» на сайте вдвое больше строк — это не потеря (16.11.2026).
- Длинные выдачи догружаются прокруткой; скрипт крутит до конца (у фамилии на 1700 дел — пара минут).
- Распознавание Vision грубо читает рукопись: «нет в тексте» ≠ «нет в деле». Таблицы с фамилиями — читать глазами модели.
- Пауза между поисками ≥4 с; капча, 403/429 — стоп и позвать владельца. Пароль и cookie скрипт не видит.
- Снимки складчин большие (уезд — 3–5 ГБ) и в git не идут: класть в `<found>/telegram/kpb_rgia/files/`.
