# Кладбища Беларуси — где искать могилу

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes archive-belarus-graves`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed archive-belarus-graves 2>/dev/null || rodo skill-notes --embed archive-belarus-graves 2>/dev/null || true`

**Что это.** В Беларуси нет одной базы кладбищ. Есть два частных сайта с одними и теми же записями, городские
терминалы в Минске и бумажные книги учёта на каждом кладбище. Этот навык говорит, что из этого работает, что уже
проверено и как спросить быстро.

**Что запись даёт.** ФИО с отчеством, годы или точные даты жизни, район, иногда кладбище, участок и снимок
памятника. На памятниках XX века часто фото-медальон — это и портрет человека.

**Чего не даст.** Деревенских кладбищ Брестской области в базах почти нет: на spachyn по всей области 1 555 имён на
757 кладбищ (Брестский район — 52 имени на 28 кладбищ). Для сравнения: Минская область — 188 тыс., Гомельская —
155 тыс. Даже большое городское кладбище бывает «неоцифровано»: пример — кладбище на 50 тыс. могил, в базе 2 записи.
Тогда участок и квадрат знает только семья или книга учёта кладбища.

**Главное правило — запросы редко.** По одному, пауза ≥4 с, без параллельных помощников. Капча или 403/429 — стоп.

## Какой сайт когда

| Нужно | Где |
|---|---|
| Есть ли человек в базе захоронений, район, кладбище | **spachyn.by** — скрипт `graves_by.py` |
| Участок и GPS гражданской могилы | pomnim.by — платно; или книга учёта кладбища (письмо) |
| Где лежит солдат, партизан, жертва войны | братские могилы на pomnim.by (бесплатно), memory.mil.by — навык `archive-belarus-db` |
| Могила на кладбище Минска (Западное, Восточное, Военное, Колодищи) | терминал на входе кладбища — только лично |
| Эмигранты, США, Канада | Find a Grave (ищется из `curl`), BillionGraves |
| Польша (Белосток, Ольштын) | grobonet, mogily.pl — уже проверяли, см. `ПОИСК_СДЕЛАНО.md` (03.11.2026) |

## Сайты

### spachyn.by — главный [проверено 04.11.2026]
- 956 516 имён, 5 633 кладбища. Собрано из открытых источников: книги учёта больших городов (Минск, Гомель), братские могилы,
  погибшие в войну. Бесплатно, без входа, работает из `curl` (страницы собираются на сервере).
- **Кладбище и район видны бесплатно** — в отличие от pomnim.by. У 99% записей есть область, у 71% — год рождения,
  у 27% — фото.
- Поиск: `GET https://spachyn.by/search?q=<Фамилия Имя>`. Понимает опечатки и латиницу, поэтому выдача шумная
  (на фамилию приходят похожие — с другой буквой или окончанием) — свои строки выбирает скрипт. Фильтры: `region`, `area`, `death_from`,
  `death_to`, `birth_from`, `birth_to`, `photo`.
- Запись: `https://spachyn.by/person/<id>-<имя-латиницей>`. Там «Место захоронения» (кладбище или «известен только
  район») и варианты написания. Услуги сайта («уточним место» 150–200 BYN, уход 300–350 BYN) — не заказываем.
- Каталог кладбищ: `/cemeteries/<область>/<район>` — сколько записей у кладбища и «оцифровано» ли оно. Перед поиском
  по деревне смотреть сюда: «неоцифровано» и 0 записей — искать бесполезно.

### pomnim.by — «Помним» [проверено 07.08 и 04.11.2026]
- ~787 тыс. захоронений, те же записи, что у spachyn (ID другие).
- Поиск: `GET https://pomnim.by/search?surname=<Фамилия>&name=<Имя>`; область — `&region=` (Брестская 348, Витебская
  350, Гомельская 346, Гродненская 349, Минская 351, Могилёвская 347). **`?q=` молча отдаёт всю базу** — не путать
  с «нашлось много».
- **Место гражданской могилы скрыто** («Беларусь» и «Получить полный доступ»); у братских могил место бесплатно.
  Поэтому место смотрим на spachyn, а pomnim — только если там записи нет.
- `pomnim.online` — российская база (Смоленск и др. — для российских веток можно; для Беларуси — нет).

### Find a Grave, BillionGraves [проверено 04.11.2026]
- Find a Grave отвечает из `curl`:
  `https://www.findagrave.com/memorial/search?lastname=<Фамилия латиницей>&location=Belarus&locationId=country_88`.
  По Беларуси кладбищ у волонтёров почти нет. Полезен для США и Канады (эмигрантские ветки).
- BillionGraves из `curl` закрыт (Cloudflare, 403) — только браузер. По Беларуси есть отдельные католические кладбища
  Гродненщины (польские надписи), Бреста не видно. Его указатель есть и на FamilySearch (коллекция 2026973).

### Книги учёта и терминалы — не онлайн
- Каждое городское кладбище ведёт книгу учёта захоронений: ФИО, дата похорон, участок. Запрос — письмом в организацию,
  которая содержит кладбища города (обычно городское ЖКХ); очередь писем — `<папка поиска>/requests/00_ПАКЕТЫ.md`
  (книгу учёта — только если ЗАГС ответит «записи нет»).
- В Минске на четырёх кладбищах (Западное, Восточное, Военное, Колодищи) терминалы: ищут по ФИО и датам. Только лично.

## Скрипт `graves_by.py`

```bash
rodo graves-by name "Фамилия Имя" --died 2016     # один запрос, совпавшие помечены
rodo graves-by person "<Имя карточки>"            # по карточке: свои строки
rodo graves-by tree --max 40                        # все умершие в Беларуси с 1941 г.
```

- Женщину ищет и под своей фамилией, и под фамилией каждого мужа: хоронят под фамилией мужа.
- Метки: **[сильное]** — фамилия, имя и год смерти ±1; **[по рождению]** — год рождения ±1, года смерти в базе нет;
  **[имя]** — лет нет совсем. Годы есть, но не сходятся — тёзка, не показывается.
- Свой ли человек — по отчеству (= имя отца в карточке). «Сильное» без отчества — ещё не факт: сверка по навыку
  `card-rules`, `known.py` до слова «нашлось».
- После прогона — строка в журнал: `searched.py add spachyn.by "<запрос>" "" "<кого>" "graves_by.py" "<итог>"`.

## Не повторять
- Не искать онлайн деревенские кладбища и кладбища с пометкой «неоцифровано». Сначала каталог кладбища: «неоцифровано» — стоп.
- Не платить pomnim.by вслепую. Если платить — только за запись, которая уже нашлась и нужна.
- Похожая фамилия в выдаче (другая буква, другое окончание) — не наш человек. Скрипт их отсекает; руками не «доверять» им.
