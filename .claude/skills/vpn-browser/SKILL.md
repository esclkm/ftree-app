# Как достучаться до закрытых сайтов (и что такое .wbh-profile)

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes vpn-browser`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed vpn-browser 2>/dev/null || rodo skill-notes --embed vpn-browser 2>/dev/null || true`

Метки: **[П]** — проверено по переписке/файлам 30.09–02.10.2026, **[В]** — вывод/предложение.

## Пошагово для исполнителя

1. **Определи, чего хочешь.**
   - Российский сайт (gwar.mil.ru, rusneb.ru, pamyat-naroda.ru, goskatalog.ru) → шаги 2–4.
   - Сайт WBH (wbh.wp.mil.pl, Варшава) → VPN не нужен: он открыт из Польши [П], см. раздел «.wbh-profile».
   - Geneteka → VPN **не** для Claude, см. скилл `archive-geneteka`.
   - Сайт со входом (FamilySearch и др.) → скилл `archive-familysearch`, вход делает Павел.
2. **Проверь доступ:** `curl -s -o /dev/null -w "%{http_code}\n" --max-time 15 https://gwar.mil.ru/` (или нужный адрес). Страну текущего адреса: `curl -s --max-time 5 https://ipinfo.io/country`.
   - `PL`/`000` на российский сайт — закрыт [П].
   - Ответ rusneb: «Отключите VPN» — сайт не любит и зарубежный адрес, и VPN-метки; через российский прокси открылся [П].
   - `403`/`429`/капча → **стоп**, скажи Павлу.
3. **Попроси Павла — не делай сам** (напиши в чат): «Сайт закрыт из Польши. Включи российский VPN и напиши "включил" — или разреши искать бесплатные российские прокси только для открытых страниц этого сайта.»
   - «включил» → повтори шаг 2. Если сайт открылся, работай в рамках скилла сайта; когда закончишь, напомни Павлу выключить. Если Claude/интернет отвалился — Павел выключает VPN, переходим к прокси [В: Claude заблокирован из России, при полном VPN сессия может умереть; сам не проверяли].
   - «да, прокси» → шаг 4.
   - молчание → жди; обходов не придумывай.
4. **Прокси (проверено) [П].** Только открытые страницы; пароли, куки, входы — никогда.
   - Список: `curl -s https://raw.githubusercontent.com/proxifly/free-proxy-list/main/proxies/countries/RU/data.txt` (строки `socks5://IP:порт`; заменяй на `socks5h://`, чтобы имя сайта разрешалось на стороне прокси).
   - Живые и российские: для каждого `curl -s --max-time 10 -x <прокси> https://ipinfo.io/country` → `RU`. Запускай по одному в цикле `for … &; wait` (одна команда `xargs` с огромным списком падает).
   - До самого сайта: `curl --cacert ca_all.pem -x <прокси> -o /dev/null -w "%{http_code}" https://gwar.mil.ru/` → `200`. Сертификат Минцифры — как в скилле `archive-gwar`, шаг 3 (root + sub + sub 2024 с `gu-st.ru`; в систему не ставить; `-k` нельзя).
   - Рабочие прокси живут часы; при `000`/обрыве — следующий; список искать заново в каждой сессии. 30.09 из 867 дошли 2.
5. **Не копируй ничего из браузера Павла** (куки, токены) и не проси у него паролей/данных VPN — никогда.

## Что это и когда

Раньше в `CLAUDE.md` и плане оркестрации было сказано, что `.wbh-profile` «нужен для VPN». Проверка показала, что это **неверно** [П]:
- `tools/scripts/wbh_cdp.mjs` (в старой истории проекта, 26.09) — маленький помощник для Chrome с удалённым управлением. В шапке команда запуска: Chrome с `--remote-debugging-port=9222 --user-data-dir="$PWD/.wbh-profile"` и адресом `https://wbh.wp.mil.pl/pl/skanywyszukiwarka_zaawansowana/`. Команды помощника: `targets`, `nav <url>`, `url`, `eval '<js>'`, `shot`, `imgdata`.
- WBH — Военно-историческое бюро Варшавы (польский сайт, открыт из Польши, в обычном браузере без капчи) [П]. Профиль создан для поиска солдата в базе WBH; что искали и что нашли — в заметках дерева.
- Профиль весит 293 МБ — это кэши Chrome; настоящих входов в нём для нас нет [В: логинов в переписке не видно]. В `.gitignore` строка `.wbh-profile/` (строки 8–10).
- **Никакого VPN-браузера в проекте не настроено**: ни расширения, ни настроек прокси, ни приложения VPN, которое запускает Claude. Единственное, что открывало российские сайты, — прокси + curl (см. шаг 4). Встроенный браузер Claude gwar не открыл («navigation denied or failed») [П]; Chrome-расширение на gwar не пробовали [В].
- Это исправлено (`3_research/<папка поиска>/проект/ХРАНЕНИЕ.md`): профиль можно **не переносить** — он пересоздаётся (раздел ниже).

## Вход/доступ

- Встроенный браузер Claude (панель справа): вход на сайты делает Павел сам. Сохраняет ли панель вход между сессиями — **не доказано** [В]: 30.09 в сессии cd18b74b вход в FamilySearch делался в 11:06, а в 4d72bfa5 в 19:12 новая панель снова попросила войти, и Павел вошёл заново [П]. Считай: вход нужно просить каждый раз.
- Никогда не проси у Павла пароли, куки, токены, данные VPN; не копируй куки со страницы в curl или файл.
- Приложение/провайдер VPN Павла в переписке не названо [П: не найдено]. Спроси один раз: «Каким VPN пользуешься и есть ли выход через Россию?» — но ответ не записывай с логинами.

## Как искать

Это не поиск, а доступ; поиск — в скиллах сайтов (`archive-gwar`, `archive-familysearch`, `archive-geneteka`).

## Как читать дёшево

Проверки доступа — одной строкой `curl -w "%{http_code}"`; тело страниц не печатать; снимки экрана не делать.

## Как сохранить без участия Павла

Всё, что связано с прокси и curl, делается без Павла, **после его «да»** на прокси. Скачанное — по скиллу сайта; сертификаты и списки прокси — во временную папку `$ARCHIVES_LOCAL/_tmp/` (вне проекта), не в git.

## Куда класть

- Сертификаты `ca_all.pem`, списки прокси, скрипты-однодневки: `$ARCHIVES_LOCAL/_tmp/`.
- Скачанное с сайтов — по таблице в `3_research/<папка поиска>/проект/ХРАНЕНИЕ.md` (сырьё — `$ARCHIVES_LOCAL/raw/<сайт>/…`; находка о родственнике — `1_sources/found/archives_online/<сайт>/…`; каталог — `3_research/archives/catalog/<сайт>/`).
- Вывод о способе доступа — в паспорт сайта `3_research/archives/sites/<сайт>.md`.

## После переезда дерева в другую папку — что переделать

1. **`.wbh-profile` не переносить.** Он в `.gitignore`, при клонировании на новое место не появится. Нужен только для WBH: пересоздать командой из шапки `wbh_cdp.mjs`, запустив из корня нового проекта (путь `"$PWD/.wbh-profile"` — относительный, переносится сам):
   `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --remote-debugging-port=9222 --user-data-dir="$PWD/.wbh-profile" "https://wbh.wp.mil.pl/pl/skanywyszukiwarka_zaawansowana/"`
   Если всё же перенести (293 МБ): `mv`, не копировать через iCloud; файлы Chrome зашифрованы ключом «Chrome Safe Storage» в связке ключей этого Mac — на другом компьютере входы не откроются [В].
2. **`.gitignore` нового репозитория** — строка `.wbh-profile/` должна быть (иначе 293 МБ уйдут в git).
3. **Пути в ОРКЕСТРАЦИИ и скиллах**: `$ARCHIVES_LOCAL/` есть с 02.10 (`raw/gaso`, `raw/rusneb_2026-09-30`, `text`); `_tmp` — `mkdir -p` при первой нужде; путь — `paths.ARCHIVES_LOCAL` (переменная окружения `ARCHIVES_LOCAL` переопределяет).
4. **Сертификаты Минцифры и список прокси** жили во временной папке сессии (`/private/tmp/claude-501/…/scratchpad`) — пропали, ничего не переносить; в новой сессии собрать по шагам `archive-gwar`.
5. **Старая выгрузка** `1_sources/found/archives_online/gwar_2026-09-30/` (JSON ≈2 МБ) переедет по таблице хранения (в скиллах путь `.../gwar/` без даты); `rusneb_2026-09-30/` (PDF) уже в `$ARCHIVES_LOCAL/raw/rusneb_2026-09-30/` (02.10).
6. Встроенный браузер Claude и его вход — привязаны к приложению, не к папке; после переезда вход FamilySearch просить заново, как и сейчас.
7. Папка проекта в `~/Documents` синхронизируется iCloud — не класть `.wbh-profile` и `_tmp` туда: iCloud сделал бы копии «… 2» (так уже потеряли `data/people`).

## Что ломалось

- Попытка скачать списки прокси в начале была заблокирована системой безопасности как «выход за рамки»: нужно явное «да» Павла в чате [П].
- Диагностика сертификата «без проверки» была заблокирована как ослабление защиты [П] — решили добавить недостающий сертификат, а не отключать проверку.
- Docker не помог бы: контейнер выходит через тот же польский адрес [П, рассуждение сессии].
- «Отключите VPN» на rusneb при заходе напрямую [П].

## Условия сайтов и риски

- Бесплатный чужой прокси видит всё, что через него идёт: только открытые страницы, без входов и данных семьи.
- Включённый VPN на всём компьютере меняет адрес и для других сайтов (FamilySearch, Geneteka могут пометить смену адреса) [В].
- Нарушать условия сайтов и обходить капчу/платный доступ нельзя; «Память народа» закрыта из-за рубежа (403) [П по плану].
- **27.10.2026 [П]:** ОБД «Мемориал» (obd-memorial.ru) открывается из Польши **напрямую** и во встроенном браузере:
  поиск `html/search.htm?f=<фамилия>&n=<имя>&s=<отчество>&y=<год>`, скан — на странице записи (картинка
  `images3?…` отдаётся только внутри страницы, curl получает заглушку → читать помощником в браузере).
  Ответ сначала приходит заглушкой «Идет поиск» (≈20 КБ) — повторять тот же адрес раз в 6 с, обычно 2–4 раза.
  **03.11.2026 [П]:** фильтр по месту рождения `pb=T~<текст>` (подсказка из ex-ussr-kinship-research) этим адресом
  **не работает**: контроль «<фамилия>» + «<деревня>» вернул всех однофамильцев. Место отбирать самим из колонки «место».
  «Память народа»: curl — 401, встроенный браузер — капча «выберите символы» → стоп, проходит Павел.

## Где нужен Павел

Включить VPN или разрешить прокси; ответить, каким VPN он пользуется; входить в сайты со входом. Всё остальное по доступу — без него.
