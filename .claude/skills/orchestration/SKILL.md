# Кто какую работу делает и как не тратить лишнее

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes orchestration`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed orchestration 2>/dev/null || rodo skill-notes --embed orchestration 2>/dev/null || true`

**Что это.** Правила, по которым главная сессия (Opus) только думает и решает, а читают, слушают, качают и проверяют
скрипты, бесплатные модели на Mac и дешёвые модели по подписке. **Зачем:** в сентябре 2026 несколько сессий потратили
по ценам API $74–178 каждая, хотя полезной работы в них было на доли этого. Коротко правила — в `CLAUDE.md` («Экономно»).

## Три слоя

| Слой | Кто | Что делает | Что в его разговоре |
|---|---|---|---|
| Дирижёр | главная сессия, Opus | решает, что искать; пишет карточки, биографии; говорит с Павлом | только текст и короткие итоги |
| Помощник | `Agent` (haiku/sonnet) | смотрит картинки, листает сайт, читает длинное — разово, по просьбе дирижёра | что угодно — выбрасывается после работы |
| Конвейер | скрипт + `claude -p` налегке (3.2) или локальная модель | массовая работа: страницы, куски аудио, пачки проверок | разговора нет |
| Конвейер на чужом лимите | скрипт + GitHub Copilot CLI (`llm.py --model copilot:…`) | то же, но не тратит подписку Claude | разговора нет |
| Скрипт | Python | качает, режет, ищет, считает, проверяет | — |

Помощник и конвейер отдают **до 20 строк** или JSON в файл: что нашёл, где (файл, страница), уверенность, нужна ли
доработка человеком. **Любое распознавание кэшируется** по контрольной сумме файла: дважды одно не распознаём.

## `claude -p` налегке — через `llm.py` (замер 01.10.2026)

| Как запускать | Токенов на старте одного вызова |
|---|---|
| Из папки проекта (так сейчас делает `bio_autotranslate.py`) | **47 000** — грузит `CLAUDE.md`, память, настройки |
| Из пустой папки + свой короткий системный промпт (`--system-prompt`) | 2 900 |
| То же + `--setting-sources ""` (без личных настроек) | **600** |

Отсюда правило: **все вызовы конвейера — через одну обёртку** (`tools/scripts/llm.py`, сделано 02.10), которая:
- запускает `claude -p` из пустой папки кэша, с `--system-prompt`, `--setting-sources ""`, `--disable-slash-commands`,
  `--strict-mcp-config`, `--no-session-persistence`, модель по задаче (haiku по умолчанию);
- картинку даёт через инструмент `Read` (только он: `--tools Read`) — хуки проекта при этом не грузятся, вопроса Павлу
  не будет;
- пишет каждый вызов в журнал `llm_calls.jsonl` в папке кэша (дата, задача, модель, токены, длительность);
- держит **дневной потолок вызовов** (настройка) и останавливается при ответе «лимит исчерпан», не повторяет в цикле;
- кэширует ответ по (контрольная сумма входа, промпт, модель).

`--bare` не подходит: он работает только с ключом API [П]. Подписка: `claude -p` — штатный режим Claude Code, но лимит
(5-часовое окно и неделя) **общий с главной сессией**; потолок конвейера — 25 % недельного лимита (решение 01.10).

## GitHub Copilot — второй конвейер со своим лимитом (с 08.10.2026)

**Что это.** У Павла подключён GitHub Copilot CLI (`copilot`). У него **свой месячный лимит запросов**, отдельный от
подписки Claude. Работа, отданная ему, не тратит лимит главной сессии. Внутри — те же Claude (Haiku, Sonnet, Opus),
а ещё Gemini и GPT. Список моделей — `copilot help config` (раздел `model`).

**Как звать — только через `llm.py`**: модель с приставкой `copilot:`. Кэш, журнал и потолок те же, только счёт свой.
```bash
echo "текст" | rodo llm ask --task <задача> --system "<правила>" --model copilot:gemini-3.8-flash
rodo llm ask … --model copilot:claude-sonnet-5.5 --image <вырезка.jpg>
rodo llm status          # сегодня: Claude и Copilot раздельно, цена по счёту GitHub
```
`llm.py` запускает `copilot` из пустой папки. Инструментов нет (`--available-tools=`), AGENTS.md и встроенные MCP
не грузятся. Картинки идут вложением. Начало вызова — около 3 тыс. токенов (с инструментами было бы 17 тыс.).
Дневной потолок — `LLM_COPILOT_CAP`, по умолчанию 100 вызовов.

**Цена.** GitHub считает каждый вызов в своих единицах. В журнале это поле `premium`. Замер 08.10.2026:
один короткий вызов Gemini 3.8 Flash — `premium` 14, и с картинкой тоже 14. Свою месячную норму Павел видит в
настройках GitHub. Перед большой пачкой — посчитать: число вызовов × цена из журнала.

**Что отдаём Copilot** (решение Павла, 08.10.2026):

| Работа | Как | Модель | Что остаётся главной сессии |
|---|---|---|---|
| Перевод биографий PL / ES / EN | `bio_autotranslate.py --model copilot:claude-haiku-4.5` (навык `bio-translate`) | та же Haiku | ничего: перевод — по разделам, как раньше |
| Сверка расшифровок аудио | `llm.py ask` с `draft.txt`: выписать места, где проходы расходятся или звучит бессмыслица (навык `audio-interview`, шаг 1) | Gemini Flash или Haiku | прочитать черновик и решить, что верно |
| Черновое чтение вырезок метрик | `metric_review.py read --model copilot:claude-sonnet-5.5` (навык `metric-search`) | Sonnet; Gemini — только после пробы | «наш / не наш» решает Павел по скану |
| Черновое распознавание машинописи и простых документов | `llm.py ask --image <страница>` (навык `archive-ocr`) | Gemini Flash | сверка цифр и имён со сканом, факты в карточки |

**Чего Copilot не делает:** не пишет карточки и биографии, не связывает людей, не решает, кто кому родня. Он не знает
правил проекта, а `llm.py` их ему намеренно не даёт. Его ответ — черновик в файл. Как с любым черновиком модели:
сверить со сканом, особенно топонимы, даты и цифры.

**Gemini.** 02.10.2026 его вычеркнули: Gemini 2.5 Flash зациклился на метрике, выдавал одно «[нрзб]». В Copilot
теперь 3.7 и 3.8 Flash. Для перевода и машинописи их можно брать. Для метрик — только после пробы на вырезках,
которые Павел уже проверил сам: та же пачка у Sonnet и у Gemini, кто меньше ошибся. Модель без согласия Павла
не меняем.

Если `llm.py` пишет «нет программы copilot» или ошибку входа — Павлу набрать `copilot login` в Терминале.

## Программно, а не ИИ

Всё, что можно сделать кодом, делается кодом. **Хуки git и Claude — только скрипты**: они проверяют, пересчитывают
производное и **пишут отчёт** («переводы: пора 27», «нет в описи медиа: 3»). ИИ-шаги (перевод, распознавание, разбор)
запускаются отдельной командой, по решению, и пишут результат в файл, который потом проверяют. Скрипт, который
сам зовёт модель, — только через `llm.py`, с журналом и потолком.

## Правила главной сессии

1. Картинки и PDF — помощнику или конвейеру (хук спросит Павла).
2. Браузер — текстом; снимки уменьшенные; ответы скриптов в странице — короткий JSON, длинное — в файл.
3. Вывод команд — коротко; свои скрипты печатают сводку, подробности — в файл.
4. Распознавание — конвейером и с кэшем; дважды одно не распознаём.
5. Одна задача — одна сессия; ~150 тыс. токенов или ~150 шагов — записать итог в журнал и предложить новую.
6. Большой разговор не оставлять без дела дольше часа: после паузы он загружается заново по полной цене.
7. Абонемент архива — только качать; читать потом, по списку «что ищем».

## Планы и журнал

- Что сделано и почему — `3_research/<папка поиска>/проект/ОРКЕСТРАЦИЯ_ЖУРНАЛ.md` (новое сверху; там же полные тексты закрытых фаз). Большую работу
  закончил — строка в журнал: что сделано, что дальше.
- Отдельные большие планы: метрики — `3_research/<папка поиска>/проект/МЕТРИКИ_СХЕМА.md`; сайт для родни (вход, права, заметки) —
  `3_research/<папка поиска>/проект/ПЛАН_ДОСТУП_И_ПРАВА.md`; движок и `rodo` — `3_research/<папка поиска>/проект/ПЛАН_ДВИЖОК_И_КОМАНДА.md`. Что искать о людях —
  `<папка поиска>/ПОИСК_ДАЛЬШЕ.md` (вход; задачи — `ПОИСК_ОНЛАЙН.md`, `ПОИСК_ОФФЛАЙН.md`, сделанное — `ПОИСК_СДЕЛАНО.md`).
- Где что хранится — `3_research/<папка поиска>/проект/ХРАНЕНИЕ.md`. Решения Павла, его дела и открытые вопросы — `3_research/<папка поиска>/проект/РЕШЕНИЯ.md`.
- Сессия не уложилась (~150 тыс. токенов или ~150 шагов) — записать сделанное в журнал и предложить новую сессию со
  стартовой фразой.
