## Что это и когда

Это сайт-каталог польских государственных архивов. Входить не нужно, он открыт всем [П]. Слова, которые нужны, чтобы читать сайт:
- **zespół** — «фонд»: коробка с делами одного учреждения (например «Sąd Okręgowy w Białymstoku» — окружной суд).
- **jednostka** — «дело»: одна папка внутри фонда. У неё есть **sygnatura** — шифр, как почтовый адрес: `2/213/0/9/18113` (архив/фонд/…/номер). Шифр пишем в письмо в архив.
- **skany** — оцифрованные снимки дела; у многих дел их нет («brak skanów/zdjęć»).
- Архивы: AAN — Archiwum Akt Nowych (Варшава, новая история), AGAD — старые акты, AP Białystok / AP Olsztyn — областные архивы.

Это не метрические книги по фамилиям: метрики Подляшья и Полесья в основном на FamilySearch и Geneteka. Здесь ищем **что за дело лежит про деревню или человека** (кооператив, суд, земельные дела) и берём шифр. Фамилии внутри описей находятся только там, где кто-то вписал имя в название дела (пример — дело вида `Zielonka Jan` в фонде консульства РП, 1936).

Что уже искали — в заметках дерева и в журнале (`searched.py query`). Смотри туда, чтобы не повторять.

## Пошагово для исполнителя (читай первым)

Инструменты — только встроенный браузер: `mcp__Claude_Browser__navigate`, `get_page_text`, `find`, `javascript_tool`. Для скачивания одной картинки допустим `Bash` с `curl` (ниже, только размер `_mid`).

**Железные правила**
- Входа нет — **паролей, cookie и токенов не нужно**. Ничего не копируй из страницы в `curl` и в файлы, кроме **публичных** адресов картинок.
- Капча или «Request unsuccessful. Incapsula incident» → **стоп**, скажи владельцу дерева, обходить не пытайся.
- 403 / 429 / страница зависла дважды → **стоп**, пауза ≥10 минут.
- Паузы между запросами ≥3 с. Скачивание — только дел про наших людей, не весь фонд.
- Скриншоты — нет. Весь текст берётся через `javascript_tool` / `get_page_text`. Картинки дел (сканы) читай не сам: отдай помощнику (`Agent`, haiku/sonnet, ответ ≤20 строк).

**Шаги**
1. `navigate` → `https://www.szukajwarchiwach.gov.pl/` (главная). **Не** открывай сразу `…/wyszukiwarka?q=…`: в сессии панель на таком адресе зависла (`get_page_text timed out after 30s`) [П].
2. Поиск — через форму на главной, **скриптом, без координат мыши** [П, проверено 02.10]. Один вызов `javascript_tool`:
```js
const i=document.querySelector('input[id$="_keywords"]'); i.value='Zielonka'; document.querySelector('button[id$="_ptas"],input[id$="_ptas"]').click(); 'sent'
```
   Ответ `sent`. Страница уйдёт на `https://www.szukajwarchiwach.gov.pl/wyszukiwarka`.
3. Подожди 4 с (`javascript_tool`: `await new Promise(r=>setTimeout(r,4000))` внутри следующего вызова) и прочитай результат сниппетом «list» (ниже). Ожидаемый ответ: массив из до 15 дел: `id`, название, шифр `sygn`, годы. Заглавие результата «Wyniki wyszukiwania - Szukaj w Archiwach».
   - Пустой массив и в тексте нет результатов → смени написание (польское, без диакритики и с ней: Łomża / Lomza, Zielonka).
   - Видишь «Incapsula» / пустую страницу / капчу → стоп (см. правила).
4. Дело: `navigate` → `https://www.szukajwarchiwach.gov.pl/jednostka/-/jednostka/<id>`, затем `get_page_text` с `max_chars: 3000`. Ожидаемо: «Sygnatura …, Daty …, Archiwum …, Zespół …, Skany …».
5. Сканы дела: на странице дела по 20 картинок. Сниппет «hashes» ниже даёт 20 хэшей (64 шестнадцатеричных знака). Следующая страница снимков — адрес с `_Jednostka_cur=2` (шаблон ниже).
6. Скачать: `Bash` → `curl` по шаблону «`_mid`» (раздел «Как сохранить»). Ожидаемо: `200 <байты> image/jpeg`. Если `200 842 text/html` (или 212 байт) — это заглушка защиты, значит адрес без `_mid` или нет `Referer` → вернись к `_mid`.
7. Результат — в файл (раздел «Куда класть»), строку — в каталог, находку — в карточку и в `ПОИСК_ДАЛЬШЕ.md`.

## Вход, VPN, профиль

- Вход **не нужен**, владелец дерева для поиска **не участвует** [П]. VPN **не нужен** — сайт открывался из Польши и Беларуси без него (в логах VPN не упоминался) [П].
- Браузер — **встроенная панель** Claude Code Desktop [П]. Расширение «Claude in Chrome» тоже открывало сайт (вкладка `tab-1`), но подключается не всегда.
- Защита сайта — **Incapsula** (Imperva). `curl` с главной и страницы поиска получает 212-байтную страницу с `_Incapsula_Resource` вместо результатов [П]. `WebFetch` тоже не годится — «закрыт защитой Incapsula». Обход защиты не нужен и не разрешён: работаем настоящим браузером.

### Сниппеты (проверены; секретов нет)

**list — результаты поиска** (на странице `/wyszukiwarka`; флаг «есть сканы» не добавляй — в проверке 02.10 он выходил ложным):
```js
JSON.stringify([...document.querySelectorAll('a[href*="/jednostka/-/jednostka/"]')].filter((a,i,arr)=>arr.findIndex(b=>b.href===a.href)===i).slice(0,15).map(a=>{const row=a.closest('li,tr,article,div.result,div')||a; const tx=row.innerText.replace(/\s+/g,' '); return {id:a.href.split('/').pop(), t:a.innerText.trim().slice(0,70), sygn:(tx.match(/sygnatura:\s*([\d\/\-\.A-Za-z]+)/)||[])[1], lata:(tx.match(/\[(\d{4}[^\]]*)\]/)||[])[1]}}))
```
Ответ — массив вида `{"id":"1234567","t":"\"Kasa Stefczyka\" w Zielonce …","sygn":"2/213/0/9/12345","lata":"1928 - 1937"}` … Если в `id` стоит `…#opis_obiektu` — обрежь всё после `#`. Число всех находок — в тексте страницы после слова «Wszystko».

Тот же результат текстом (для чтения глазами): `document.querySelector('section').innerText` — после слова `Wyniki` идут блоки «название / rok/lata / sygnatura / archiwum / tagi i indeksy» [П].

**hashes — снимки на странице дела** (на странице `/jednostka/-/jednostka/<id>`, подожди 3 с после загрузки):
```js
await new Promise(r=>setTimeout(r,3000)); [...new Set([...document.querySelectorAll('img')].map(i=>i.src).filter(s=>/photos\.szukaj/.test(s)).map(s=>s.replace(/_mid$/,'').split('/').pop()))].join('\n')
```
Ответ 02.10 (дело XVIII века с 40 снимками): 20 строк по 64 знака. Всего снимков в деле было 40 — две страницы по 20.

## Как читать результаты дёшево

- Дело читается `get_page_text` (`max_chars` 1500–3000) — текст без картинок [П]. Поле поиска `find "Szukaj textbox search"` ничего не нашло [П]: `find` тут ненадёжен, бери `javascript_tool`.
- Результаты — короткий JSON из сниппета «list». Длиннее 4000 знаков не выводи; лишнее — `.slice(...)` и повтор.
- Сканы: ≈ 600–800 px по длинной стороне у `_mid`; для почерка XVIII века хватило, чтобы понять «ничего нет» [П]. Читать скан самому — дорого: склей по 4 снимка в одну сетку (`PIL`, как сделано в cd18b74b: `g_01.jpg` из `m_01…04`) и отдай помощнику, а не смотри 40 картинок подряд.

## Как сохранить без участия владельца

**Рабочий рецепт [П]:** картинка среднего размера через `curl` с заголовком `Referer`, без cookie и без входа. Проверено 30.09 и 02.10 (адрес — любой из хэшей со страницы дела):
```bash
mkdir -p $ARCHIVES_LOCAL/raw/szukajwarchiwach/<sygnatura-со-знаками-минус>
cd $ARCHIVES_LOCAL/raw/szukajwarchiwach/<sygnatura-со-знаками-минус>
n=1; for h in <hash1> <hash2>; do curl -sS -m 20 -A "Mozilla/5.0" -e "https://www.szukajwarchiwach.gov.pl/" -o $(printf "m_%02d.jpg" $n) "https://photos.szukajwarchiwach.gov.pl/${h}_mid" -w "%{http_code} %{size_download} %{content_type}\n"; n=$((n+1)); sleep 3; done
file m_*.jpg | grep -vc JPEG   # ожидаем 0 — все файлы настоящие JPEG
```
Ожидаемый вывод по каждому файлу: `200 137974 image/jpeg`. В сессии 30.09 так скачали 40 снимков одним циклом без единой ошибки [П] (пауза в той версии не ставилась; сейчас ставь 3 с).

**Полный размер `_max` (2500×1820, ≈1 МБ) — без диалога «Сохранить» [П 15.10.2026]:** просмотрщик сайта
(`/o/nac-custom-theme/js/plugins/photoslider/dist/index.html?plikid=…&jednostkaid=…`) грузит `https://photos.szukajwarchiwach.gov.pl/<hash>_max`.
`curl` на `_max` получает заглушку защиты (≈1 КБ html) даже с заголовками браузера; встроенная панель открывает, но `<a download>`
там зовёт диалог сохранения, а отправка на `127.0.0.1` запрещена. Рабочий путь — свой Chrome проекта:
```bash
rodo browser-cdp start
rodo browser-cdp batch $ARCHIVES_LOCAL/raw/szukajwarchiwach/<sygn>/max список.tsv --pause 3 \
  --isolated --warm https://www.szukajwarchiwach.gov.pl/jednostka/-/jednostka/<id>
rodo browser-cdp stop
```
`список.tsv` — строки «`https://photos.szukajwarchiwach.gov.pl/<hash>_max`<TAB>`имя.jpg`»; хэши — из `3_research/archives/catalog/szukajwarchiwach/<sygn>.jsonl`.
`--isolated` — своё окно-контекст: Chrome проекта один на все сессии, и без него пачка шла в общей вкладке — 15.10 другая сессия открыла там FamilySearch, и скачивание встало на 14 минут; заодно своя папка загрузок не уводит чужие файлы. `--warm` — сначала зайти на сам сайт: без этого файлы приходят по 959 байт (заглушка) — скрипт теперь считает это ошибкой (`HTML имя`). Ожидаемо: `991237 имя.jpg`.

**Что не получилось [П]:**
- `curl` без `_mid` (полный размер): `200 842 text/html` — защита отдаёт заглушку.
- `curl` на `/wyszukiwarka`: 212 байт заглушки (см. выше).
- `fetch` + `<a download>` на странице `photos.szukajwarchiwach.gov.pl/<hash>`: `TypeError: a.click is not a function` (страница-картинка не обычный документ); вариант `dispatchEvent(new MouseEvent('click'))` вызвал, но файла в `~/Downloads` через 10 с не появилось.

**Идеи [В] для полного размера (устарело — см. `_max` выше):**
- **[В]** на странице дела (`www.szukajwarchiwach.gov.pl`, не `photos…`) искать кнопку «Pobierz» (`find` «Pobierz» ничего не вернул 30.09 — возможно, кнопка появляется только при выборе снимков или входе в аккаунт). Открыть дело, отметить снимки чекбоксами, `find` «Pobierz».
- **[В]** взять из страницы адрес просмотрщика (`performance.getEntriesByType('resource')` показывал только `_mid`) и посмотреть, нет ли у просмотрщика запроса большего размера (параметр размера в адресе).
- **[В]** скачать `_mid` из страницы `fetch('https://photos…/<hash>_mid')` + `<a download>` на странице `www.…` (рецепт из `archive-familysearch`, раздел «Рабочий рецепт»), если `curl` отвалится.
Если полный размер понадобился позарез (почерк не читается в `_mid`) — спроси владельца дерева: возможно, нужен аккаунт на сайте («Zaloguj się») или письмо в архив.

Связь `father`/`spouse` — только по документу. Все пары рядом — `possible.py` → `3_research/tree/_СВЕРКА.md`. ## Что ломалось и что тратило токены

- **Прямой адрес поиска** `…/wyszukiwarka?p_p_id=Wyszukiwarka&q=…` — `get_page_text timed out after 30s`, затем `javascript_tool timed out after 45s`. Решение — форма на главной [П].
- **`curl` на сайт** — 212 байт Incapsula (см. выше). Не повторять.
- **Клик по координатам** `(385, 218)` в поле поиска сработал, но требует снимка экрана; замени скриптом из шага 2 [П].
- **«Pobierz»** в `find` не найден; `Downloads` пустой через 10 с [П].
- **Расход:** около 40 снимков по 800 px читали отдельными `Read`; склейка по 4 в одну сетку сократила число картинок в десять раз [П].
- Одноимённые деревни: в фондах областного архива находится деревня с тем же названием, но в другом повете. Название деревни надо сверять по повету и воеводству [П].

## Условия сайта и ограничения

- Сайт общий и бесплатный; сканы — материалы государственных архивов. Условия повторного использования мы в сессиях **не читали** [В]: перед публикацией снимков на сайте семьи открой правила использования сайта и спроси владельца дерева. Для личной работы и расшифровки хватает.
- Защита Incapsula реагирует на «роботные» запросы: `curl` без браузера блокируется. Работаем только через панель браузера, умеренно (одна выдача — несколько секунд паузы).
