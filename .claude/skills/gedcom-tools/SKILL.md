# Работа с GEDCOM дерева

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes gedcom-tools`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed gedcom-tools 2>/dev/null || rodo skill-notes --embed gedcom-tools 2>/dev/null || true`

> ⚠️ **Главная база дерева — Obsidian** (`3_research/tree/`, дополнение Charted Roots,
> см. `START_HERE.md` и `tools/obsidian_import/README.md`). `3_research/tree_data/enriched.ged` — исходник, из которого дерево однажды собрано;
> для новых фактов его больше не правим. Новых людей и факты вносить заметками в `3_research/tree/`,
> со ссылкой на источник. Этот скилл нужен для чтения старых GEDCOM и разбора чужих выгрузок.

## Где что лежит

- **`3_research/tree_data/enriched.ged`** — главный файл дерева (экспорт MyHeritage).
  ⚠️ **Это единственная копия. Никогда не редактировать вручную и не перезаписывать без бэкапа.**
- `<папка поиска>/people/НОВЫЕ_ПЕРСОНЫ.ged` — фрагмент с находками из архива (серия ID `@I9xxxxx@`).
- `3_research/tree_data/persons.json`, `families.json` — производные, пересобираются из GED.

## ЖЕЛЕЗНОЕ ПРАВИЛО

**Любая операция записи — только через `tools/scripts/gedcom_tool.py`, и только после бэкапа.**
Скрипт сам делает бэкап в `3_research/tree_data/.ged_backups/enriched_<ГГГГММДД_ЧЧММСС>.ged` перед каждой записью.

Ручное редактирование `.ged` в редакторе или через `sed` **запрещено**: формат строчно-иерархический
(уровень + тег), одна сбитая строка ломает всё дерево, а MyHeritage не скажет, где именно.

## Инструмент

```bash
rodo gedcom-tool <команда> [аргументы]
```

| Команда | Что делает |
|---|---|
| `check [файл]` | валидация: структура уровней, парность HEAD/TRLR, битые ссылки `@I…@`, дубли ID |
| `stats [файл]` | сводка: сколько персон, семей, у скольких есть даты рождения/смерти |
| `find <строка>` | найти персон по имени (регистронезависимо), показать ID и даты |
| `show <@ID@>` | вывести все строки одной персоны или семьи |
| `dupes` | найти вероятные дубли: совпадение имени + года рождения |
| `merge <фрагмент.ged>` | слить фрагмент в основной файл (с бэкапом, с проверкой конфликтов ID) |
| `backup` | просто сделать бэкап |
| `restore` | восстановить из последнего бэкапа |

**Порядок безопасной работы:**
```bash
rodo gedcom-tool check          # убедиться, что файл цел
rodo gedcom-tool backup         # бэкап
rodo gedcom-tool merge <папка поиска>/people/НОВЫЕ_ПЕРСОНЫ.ged
rodo gedcom-tool check          # проверить после слияния
rodo gedcom-tool dupes          # посмотреть, не наплодили ли дублей
```

## Правила для новых персон

- **ID новых персон** — серия `@I9xxxxx@`, семей — `@F9xxxxx@`. Существующие занимают `@I5xxxxx@`.
- **Связи с существующими персонами не прописывать в фрагменте** — иначе при импорте в MyHeritage
  создадутся дубликаты уже известных людей. Сшивать вручную после импорта.
- **Каждой персоне — `1 SOUR`** с указанием документа (`Doc22`, `записи бабушки` и т. п.).
- **Имена, восстановленные по отчеству**, помечать в `NOTE`:
  «ИМЯ ВОССТАНОВЛЕНО ПО ОТЧЕСТВУ …» — чтобы через год было видно, где документ, а где реконструкция.
- **Даты** — формат GEDCOM: `12 FEB 1910`, `ABT 1840`, `BET 1830 AND 1850`.
- **Кириллица** — файл в UTF-8 без BOM в теле; шапка `1 CHAR UTF-8` обязательна.

## Обновление дерева на MyHeritage

**Обновление дерева на MyHeritage** (платный тариф, дерево уже на сайте): свежая выгрузка с сайта → `1_sources/others_trees/myheritage/`,
затем `myheritage_update.py build` и `check` → `3_research/tree_data/myheritage_update.ged` → Family Tree Builder, Import GEDCOM → Merge
(сначала в копию проекта). После слияния — новая выгрузка с сайта и номера новых людей в `gedcom_id` их карточек (`lint` покажет, кому).

## Глубокие поколения

Прапрадедов и глубже вносим в дерево и изучаем как историю рода. Что в глубине действительно ценно — это
**национальность, вероисповедание и сословие**: они рисуют картину среды (православные мещане уездного города, католики
соседнего прихода, крепостные крестьяне) и иногда дают неожиданную подсказку — как отчество **«Иулиановна»**,
указывающее на католическую традицию в православной семье.

## Чего не делать

- Не вносить персон, о которых нет ни документа, ни ясного устного свидетельства.
- Не «доуточнять» даты по логике — если в документе диапазон, так и писать `ABT`.
- Не сливать фрагмент дважды — сначала `check`, потом `merge`, потом снова `check`.
- Не удалять старые заметки MyHeritage — добавлять новые рядом, помечая источник и дату.
