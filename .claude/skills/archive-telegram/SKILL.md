# Телеграм: генеалогические группы

> **Заметки этого дерева** вклеиваются ниже сами, при вызове навыка (нет заметок — пусто; вручную — `rodo skill-notes archive-telegram`). Прочитать перед работой.

!`${CLAUDE_PLUGIN_ROOT}/tools/rodo skill-notes --embed archive-telegram 2>/dev/null || rodo skill-notes --embed archive-telegram 2>/dev/null || true`

**Что это.** В Телеграме у каждого уезда есть своя группа исследователей: туда выкладывают описи архивов, указатели,
выписки из метрик, списки жителей, таблицы «какие книги где лежат». Читаем их под аккаунтом владельца дерева скриптом
`tools/scripts/tg_group.py` (Telethon) — без браузера и без токенов модели на чтение.

**Писать в группы и людям** — только по «да» владельца на каждое сообщение.
Читать, искать, скачивать файлы — можно без спроса.

## Команды — сразу к делу

```bash
rodo tg-group find "Духовщинский уезд" "Смоленский уезд"   # найти группы (название, ссылка, форум/канал, участники)
rodo tg-group topics https://t.me/<группа>                  # подгруппы форума с номерами
rodo tg-group dump https://t.me/<группа>                    # вся переписка → jsonl; повтор — только новое
rodo tg-group search https://t.me/<группа> Лесовской        # до 200 сообщений со словом, со ссылками
rodo tg-group ctx https://t.me/<группа> 76535 91919         # сообщение ±7 соседей: весь разговор
rodo tg-group get https://t.me/<группа> 254 1758            # файлы этих сообщений → <группа>/files/
```

- Выгрузка — `1_sources/found/telegram/<группа>/messages.jsonl`: `id, date, from, reply_to, text, media, file`.
  В форуме `reply_to` у сообщения верхнего уровня = номер темы (из `topics`) — так выбирают одну тему.
- Группа на 1–3 тыс. сообщений выгружается за 1–2 минуты — проще `dump` и разбирать файл питоном, чем много `search`.
  Большие (Familio по области — 90+ тыс.) — только `search` по словам.
- `search` Телеграма ищет по началу слова: «Лесовск» найдёт «Лесовской», «Лесовская».
- Вход уже сделан (`~/.config/ftree-telegram/`). Если «сначала login» — попросить владельца войти QR-кодом.
- Закрытая группа — по номеру: `dump -- -100…`. Вступать — только с согласия владельца.

## Файлы из групп: как читать

1. `get` → `1_sources/found/telegram/<группа>/files/<id>_<имя>` (найденное, не семейное; в опись — хуком).
2. PDF с текстом — `pdftotext -layout`, сразу `grep`. Скан без текста — `pdftoppm -r 200 -gray -png` + `tesseract -l rus --psm 6`
   в фоне (≈10–60 с на страницу), потом `grep`. Таблицы с «+» по годам (наличие метрик) Tesseract не читает —
   такие смотреть глазами только для одного нужного прихода (помощник, вырезка).
3. `.xlsx` без openpyxl: `zipfile` → `xl/sharedStrings.xml` → текст строк.
4. Газетные списки мелким шрифтом в колонках (списки избирателей 1906) Tesseract не читает — только Copilot по вырезке,
   и только если есть ради кого.

## Что уже прочитано

Таблица групп, которые уже прочитаны, слова, по которым искали, и группы «ещё не читали» — в заметках дерева
(`rodo skill-notes archive-telegram`). Обновлять там после каждого захода: группа, ссылка, что сделано, отчёт.

**Как устроены уездные группы.** Обычно это форумы одной команды на губернию: по группе на уезд (ник вида
`<город>_uezd`, `<город>skiy_uezd`, 100–300 участников) и одна большая группа Familio по области (`familio_<область>`).
Самая живая — обычно большая. Перебирать имена вида `<город>_uezd` — быстрый способ узнать, есть ли группа уезда.
Какие группы нашли для нашего края и каких нет — в заметках дерева.

## Что лежит в группах (чтобы не скачивать заново)

- **Смоленщина, везде одно и то же:** опись ГАСО ф. Р-653 (сельхозперепись 1917) по уездам; опись ЗАГС ф. Р-3315 по
  уездам; «Смоленский/Духовщинский уезд в ГАСО» — таблицы номеров церквей для ф. 48; «Исповедки ГАСО.docx» (сводка
  выложенных исповедных); «Все МК из АИС 28.02.2025.xlsx» — список всех оцифрованных метрик ф. 48 (24 568 строк;
  по Духовщинскому уезду — 742); «Путеводитель ГАСО 2012»; «АТД Смоленской обл. 1981» (алфавит деревень → волость);
  «Смоленский этнографический сборник 1893» (обряды, песни).
- **Духовщинский уезд:** «Духовщинская земля: православные храмы» (222 с., с текстом — история каждого прихода и
  деревни прихода); опись архива Духовщинского района 2019.
- **Фото деревень** в смоленских группах выкладывают редко — проверять поиском с фильтром «фото»:
  `iter_messages(..., search=слово, filter=InputMessagesFilterPhotos)`.
- **Описания деревень** в смоленских группах почти не выкладывают; чаще они — в ветках краеведческих форумов
  (например smolbattle.ru), ссылки на которые дают участники.
- **Происхождение фамилий:** подборка по ономастике на Яндекс-диске (@familio_smolensk/76525), словарь Унбегауна.

## Как не наступить снова

- Перед словами «нашлось», «новое» — `known.py` (правило проекта). Что уже искали — эта таблица и `searched.py query`.
- После захода — строка в `<папка поиска>/ИСКАЛИ_журнал.tsv` (`searched.py add`) и строку в таблицу выше.
- Мнение в чате («фамилию давали по книге о птицах») — не факт: в отчёт с пометкой «по словам участника», в карточку — нет.
- Сырые выгрузки и файлы — в `1_sources/found/telegram/`; эта папка **не в git** (`.gitignore`), живёт только на этом
  Mac. Всё нужное для дерева — выписать в отчёт `findings/` со ссылкой на сообщение (t.me/<группа>/<номер>).
