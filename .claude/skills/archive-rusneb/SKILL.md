## Пошагово для исполнителя (читай первым)

Правила:
- Входа в аккаунт **не нужно** — каталог и PDF открыты [П]. Паролей, cookie, токенов не спрашивать, не писать, не переносить.
- Капча, «Доступ ограничен», 403 не про VPN — стоп, скажи Павлу.
- Российский адрес — решает Павел. Не включай и не ищи прокси сам без его «да» (в сессии 30.09 это блокировала система безопасности, пока не было слов Павла).

Шаги:
1. **Не качай то, что уже есть.** Проверь: `rodo archives have rusneb` (каталог `3_research/archives/catalog/rusneb/`: код, адрес, сумма, есть ли копия на этом Mac), `1_sources/found/archives_online/` и `3_research/tree/sources/`. Скачал новое — впиши в `RUSNEB` (`tools/scripts/archives.py`) и `archives.py build rusneb`. Что уже скачано для этого дерева — в заметках дерева.
2. **Проверь доступ:** `curl -s -o /tmp/rn.html -w "%{http_code}\n" --max-time 25 -A "Mozilla/5.0 (Macintosh)" https://rusneb.ru/ ; grep -o "<title>[^<]*" /tmp/rn.html`
   - `200` и заголовок НЭБ — всё открыто, иди к шагу 4.
   - `403`, в заголовке «Отключите VPN — НЭБ» — адрес не российский (из Польши так [П]) → шаг 3.
   - `000` — сеть; повтори через минуту; если снова — спроси Павла.
3. **Спроси Павла:** «rusneb.ru не открывается из Польши. Включи российский VPN и напиши "включил", либо разреши использовать бесплатный российский прокси только для запросов к rusneb (вход и пароли через него не вводим).» Дальше:
   - «включил» → повтори шаг 2 (если отвалился сам Claude — Павел выключает VPN и выбирает прокси) [В].
   - «разрешаю прокси» → способ в скилле `archive-gwar` («Прокси») [П]; здесь добавь только `-x socks5h://IP:PORT` ко всем `curl`.
   - Нет ответа — жди. Обходов не искать. Альтернатива без России: если книга есть на другом сайте (например, списки населённых мест бывают на elib.rgo.ru [П]) — берём оттуда.
4. **Найти книгу:** поиск `https://rusneb.ru/search/?q=<слова процент-кодом>`; в ответе ссылки вида `/catalog/<код>/`. Достать их:
   ```sh
   q="приходов Смоленской епархии"; u="https://rusneb.ru/search/?q=$(python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "$q")"
   curl -s -A "Mozilla/5.0 (Macintosh)" "$u" -o rs.html; python3 - <<'E'
   import re,html
   s=open('rs.html',encoding='utf-8',errors='ignore').read()
   for m in re.finditer(r'href="(/catalog/[^"/]+/)"[^>]*>(.*?)</a>',s,re.S):
       t=html.unescape(re.sub(r'<[^>]+>|\s+',' ',m.group(2))).strip()
       if t: print(m.group(1),t[:120])
   E
   ```
   Ожидаешь: строки `/catalog/000200_000018_RU_NLR_19V_000001/ <название книги>…` (номер — вымышленный образец).
5. **Карточка книги** (`/catalog/<код>/`): сними текст, найди год, число страниц, размер PDF:
   ```sh
   curl -s -A "Mozilla/5.0 (Macintosh)" https://rusneb.ru/catalog/<код>/ -o d.html; python3 - <<'E'
   import re,html
   s=open('d.html',encoding='utf-8',errors='ignore').read()
   t=html.unescape(re.sub(r'<[^>]+>',' ',re.sub(r'<script.*?</script>|<style.*?</style>','',s,flags=re.S))); t=re.sub(r'\s+',' ',t)
   i=t.find('Библиографическое описание'); print(t[i+27:i+420]); print(re.findall(r'Скачать pdf, [\d.,]+ [КМГ]Б',t)[:1])
   E
   ```
   Нет строки «Скачать pdf» → книга под защитой авторских прав, читается только в читальном зале (ЭЧЗ) — не качается; скажи Павлу.
6. **Скачать PDF:** скрипт ниже. Запускай в фоне (`run_in_background`), печатает «done файл размер». Один поток, резюмирует, проверяет `%PDF`/`%%EOF`.
7. **Прочитать дёшево** — см. «Как читать дёшево». Результат записать в `2_transcripts/`/источник; в отчёт — счётчики.

## Что это и когда
НЭБ — государственный каталог оцифрованных книг России. Для проекта это не архив людей, а **справочники**: «какая деревня к какому приходу и волости относилась», «какие церкви были в уезде», «кто служил священником». Нужен, чтобы понять, в каком церковном приходе (значит — в какой метрической книге) искать запись о предке. Какие деревни и приходы нужны этому дереву — в заметках дерева.

## Вход
Не нужен [П]. Мешает не вход, а **страна**: из Польши любая страница отвечает 403 «Отключите VPN — НЭБ» [П]. Встроенный браузер Claude, скорее всего, тоже откажет [В, как для gwar].
Как получили российский адрес 30.09 [П]: бесплатные публичные SOCKS-прокси с адресами в России (два рабочих из списка, проверенных на gwar) + `curl -x socks5h://…`. **Риск:** чужой прокси видит, куда ты ходишь; поэтому только публичные страницы, без паролей. Для rusneb сертификат Минцифры не нужен [В] (сессия подставляла общий файл `ca_all.pem`, но проверять отдельно не стали); если `curl` ругается на сертификат, возьми способ из `archive-gwar` («Сертификат»), `-k` не использовать. Вариант с VPN у Павла: скилл `vpn-browser`, если он есть в `.claude/skills/` [В].

## Как искать
- По названию: `https://rusneb.ru/search/?q=…` (шаг 4). Искать словами «росписание приходов», «список населённых мест», «историко-статистическое описание церквей и приходов» + епархия или губерния [П]; описания бывают по одному уезду — проверь, тот ли.
- «Список приходов Смоленской епархии 1904» на сайте **нет**; по ссылке из плана лежал «Список населённых мест» (в нём прихода нет, только селения и волость) [П]. Не ищи его снова.
- Поиска по тексту внутри книги у скачанных PDF нет: они — сканы без текстового слоя (`pdftotext` пусто) [П].

## Рядом: elib.shpl.ru — Историческая библиотека (ГПИБ) [В]
По vdov открыт отовсюду (у нас не проверялся): списки населённых мест, адрес-календари, памятные книжки, справочники
губерний. Поиск: `GET https://elib.shpl.ru/ru/nodes/search?query=<слово>`. Годится, когда НЭБ закрыт по стране
(403) или нужной книги там нет; для «какая деревня к какому приходу» — те же книги, что в НЭБ. Взято из vdov (CC BY 4.0).

## Как читать дёшево
- Сканы без текста: **`pdftoppm`**, не глазами в чат. Карта книги по уменьшенным страницам: `pdftoppm -r 50 -jpeg книга.pdf $S/p`, затем нужные страницы крупнее: `-r 110 -f 6 -l 12` (читаемо), `-r 170` — отдельная страница (цифры).
- Склеить несколько обрезок в одну картинку (Pillow) и показать **помощнику** (`Agent`, haiku/sonnet, ответ ≤20 строк), а не себе.
- Рабочие страницы большой книги (свой уезд, свои волости) обрезать один раз в `1_sources/found/archives_online/<книга>/*.png`. Читай их, не весь PDF.
- Номер страницы книги ≠ номер листа PDF; сверяй по печатному номеру на скане.

## Как скачать без участия Павла
[П] Рабочий рецепт 30.09 (обе книги, 22 МБ и 170 МБ, скачались за минуты). Адрес выдачи: `https://rusneb.ru/local/tools/exalead/getFiles.php?book_id=<код>&name=<название процент-кодом>&doc_type=pdf`, нужен `Referer` на страницу книги. Скрипт `dl.sh` (адаптирован: порядок «сначала без прокси, потом прокси из списка» — только если Павел разрешил):
```sh
#!/bin/sh
# dl.sh КОД "Название" ВЫХОДНОЙ.pdf [socks5h://IP:PORT ...]
ID="$1"; NAME="$2"; OUT="$3"; shift 3
U="https://rusneb.ru/local/tools/exalead/getFiles.php?book_id=$ID&name=$(python3 -c 'import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))' "$NAME")&doc_type=pdf"
for i in 1 2 3 4 5 6 7 8; do
  for p in "" "$@"; do
    X=""; [ -n "$p" ] && X="-x $p"
    curl -s -L -C - --max-time 900 $X -A "Mozilla/5.0 (Macintosh) Chrome/128" -e "https://rusneb.ru/catalog/$ID/" -o "$OUT" "$U"
    head -c 5 "$OUT" | grep -q %PDF && tail -c 1100 "$OUT" | grep -q %%EOF && { echo "done $OUT $(wc -c < "$OUT")"; exit 0; }
    echo "try $i ${p:-direct} $(wc -c < "$OUT" 2>/dev/null)"
    sleep 20
  done
done; exit 1
```
(`-C -` докачивает с места обрыва; `sleep 20` добавлено сейчас — раньше повторы шли без пауз, 40 кругов подряд [В: безопаснее с паузой].)
Пример: `./dl.sh 000200_000018_RU_NLR_19V_000001 "Росписание приходов и церквей епархии" $ARCHIVES_LOCAL/raw/rusneb_<дата>/<Название>.pdf`.
Проверка файла: `pdfinfo файл.pdf | grep -E "Pages|File size"` — страницы совпадают с карточкой.
Идея [В]: из карточки взять `Скачать pdf, N МБ` и сверять размер.

## Куда класть
- PDF-сырьё: `$ARCHIVES_LOCAL/raw/rusneb_<дата>/` (книги по 20–170 МБ — вне проекта, не в git, не в облаке; в скриптах — `paths.RUSNEB_RAW`).
- Каталог: `3_research/archives/catalog/rusneb/<код>.book.json` — код НЭБ, название, адрес, sha256, где копия (`archives.py build rusneb`).
- В проект: только страницы про наших и вывод — обрезки `1_sources/found/archives_online/<книга>/`, карточка источника `3_research/tree/sources/` (пример: «Список населённых мест <губернии> <год> — <деревня>.md»). Происхождение — `найдено`.
- **Возможно, наш — полем, не текстом.** Человек из записи о нашем человеке или прямом звене получает свою карточку; боковые ветки, крёстные и поручители — строкой в отчёте или в факте записи (`card-rules`, «только у звена»). Подозреваем, что это кто-то из дерева, — в его свойства `maybe_same: "[[X]]"` + `maybe_same_id`, или `maybe_kin: "[[X]] — брат?"` + `maybe_kin_id` (кем приходится — словом с «?»); на чём держится и что докажет — строкой со ссылкой `[[X]]` в «Открытых вопросах». Обратная сторона у X появится сама. Проверили, что нет, — `rodo possible no "<карточка>" "<X>" --why "…"` (пишет `not_same`/`not_kin`, пара больше не всплывёт). Связь `father`/`spouse` — только по документу. Все пары рядом — `possible.py` → `3_research/tree/_СВЕРКА.md`. Кандидатов из дерева под запись — `tree.py find <фамилия> --for "<имя>"`: проверенные «нет» не показываются.

## Что ломалось
- Прямой заход из Польши: 403, «Отключите VPN — НЭБ».
- Часть прокси из списка не отвечали (`000`) или сами отдавали «Отключите VPN»: нужны именно российские адреса, проверяй каждый.
- Скачивание большой книги обрывается: поэтому `-C -` и проверка `%PDF`+`%%EOF`.
- Вывод пути с кириллицей в `curl -o` работал только при существующей папке: сначала `mkdir -p` (30.09 первая попытка упала «No such file or directory»).
- «Список приходов 1904» не существует в НЭБ — искали зря, ушло около часа.
- Запрошенный «приход» в «Списке населённых мест» не указан → вывод про приход из него не сделать; нужен справочник ГАСО «Выбор церкви / Населённые пункты» или клировая ведомость.

## Условия сайта
Условия НЭБ не перечитывались [?]. Правообладатели: книги до 1918 г. свободны; для книг после 1950-х PDF нет, только читальный зал. Скачиваем для личной работы, не публикуем целиком; на сайт родни — только нужные страницы с указанием «НЭБ, код …». Массово не выкачиваем: нужные книги по одной, с паузой.
