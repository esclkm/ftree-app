# Вымышленное дерево для тестов — `sample.ged`

Что это. Маленькое родословное дерево в формате GEDCOM, придуманное руками: 30 человек, 10 семей, 2 источника,
пять поколений (1852–1985). Все люди, деревни, город и адрес вымышлены. Это **не** копия и не «обезличенная» версия
настоящего дерева: по связям и годам в нём никого не узнать. Зачем: проверять движок на чужом дереве — `rodo init` →
`rodo import gedcom tools/sample/sample.ged` → все проверки по нулям (тест `tools/scripts/tests/test_import_gedcom.py`).

Почему лежит в `tools/sample/`. Движок пока внутри `tools/`; при разделе на данные и приложение папка переедет вместе
с ним в `engine/sample/` (план — `3_research/<папка поиска>/проект/ПЛАН_ДВИЖОК_И_КОМАНДА.md`).

## Что внутри нарочно

| Что | Где | Что должно получиться |
|---|---|---|
| Дата по старому стилю (`@#DJULIAN@`) | рождение Прокопа Ясенева (I1) 12.02.1852, брак I1 и I2 20.01.1875 | главная дата — по новому стилю (24.02.1852), старая — рядом |
| Два рождения с разницей 12 дней | Анна Ясенева (I5): 3 и 15 марта 1881 | одна дата в двух стилях, не расхождение |
| Имена кириллицей и латиницей | ветка в Польше: Kazimierz, Helena, Witold, Ewa Jasieniew; Agata Wierzbowska | имена как в выгрузке |
| CONC посреди буквы | заметка I1: строка рвётся между двумя байтами «ж» в «жернова» | при чтении слово целое |
| «х» прямо перед CONC | та же заметка: «старых⏎2 CONC верб» | «х» не съедается (её второй байт — 0x85, как у NEL) |
| Разделители NEL (U+0085) | записи I20–I24 разделены NEL вместо CRLF | читаются как обычные строки |
| Братья-тёзки | Иван Ясенев 1878 (I3) и 1885 (I4), сыновья I1 | две карточки: «Иван Ясенев (1878)», «Иван Ясенев (1885)» |
| Деревня сменила государство | Вербичи: «Гродненская губерния, Российская империя» → «Werbicze, województwo poleskie, Polska» → «Брестская область, БССР» | три цепочки мест; отчёт спрашивает, одно ли это место |
| Брак и развод | I4 и Agata Wierzbowska: брак 1910, развод 1925; второй брак I4 — 1927 | события у обоих супругов |
| Ребёнок без имени | I6 — только фамилия, «INT 1883 (умер младенцем)» | карточка «Ясенев (1883)» |
| Вымышленный адрес | Сергей Ясенев (I25): RESI «Садовая, 12-34», Лесогорск | карточка дома; на сайте «Лесогорск — Садовая» без номера |
| Живые | I25, I26, I29, I30 — без даты смерти | — |
| Разные виды дат | ABT, EST, BEF, AFT, BET … AND, FROM, INT | по правилам карточки (навык `dates`) |

Файл бинарный по смыслу: в нём байты, которые редактор может «починить» (NEL, разорванная буква). Править — скриптом,
проверить — `rodo test`.
