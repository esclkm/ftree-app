## Порядок работы

**источник → расшифровка → факт в карточке → биография.**

1. Новый файл — в `1_sources/…`, имя по содержанию: `Кто_что_дата`.
2. Расшифровка — в `2_transcripts/`.
3. Факт — в карточку: одна строка — один факт, с источником и уверенностью:
   `- **Что:** значение — *источник: [[Карточка источника]], стр. · уверенность: высокая|обычная|низкая*`.
4. Рассказ — в биографию `3_research/tree/biographies/<Имя карточки> — биография.md`.
5. Проверки — `rodo check` (все разом).

Чужое дерево загружается командой `rodo import gedcom <файл>`: в пустое дерево — карточками сразу; в живое — отчётом
и подозрениями `maybe_same`, без слияний (`--dry-run` — только показать).

## Правила дерева — ядро

- **Происхождение источника** видно везде: `семья` > `найдено` > `чужое дерево` > `вывод проекта`. Факт только из
  чужого дерева — подсказка для проверки, уверенность низкая.
- **Номер важнее имени:** связь — `[[Имя]]` и `*_id` вместе (`father` + `father_id`).
- **Подозрение — полем** (`maybe_same`, `maybe_kin`; проверили «нет» — `not_same`, `not_kin`), не фразой; слияние —
  только `rodo merge-cards … --why "<доказательство>"`.
- **Догадка — не факт:** `уверенность: низкая` и на чём держится. Отчества в карточки не вносим; имена не «исправляем».
- **Даты — по GEDCOM:** `1935`, `1935-05-12`, `ABT 1935`, `BEF 1944`, `BET 1941 AND 1945`. До 1918 года главная дата —
  по новому стилю, дата документа по старому — рядом в скобках.
- **Событие на двоих — у обоих сразу:** брак, развод, рождение ребёнка — одной правкой у обеих сторон.
- **Место в факте — ссылкой** `[[Деревня|в Деревне]]`, иначе человека нет на карте.
- **Контакты живых** (телефон, почта, адрес) — в разделе «Контакты (не публикуются)»; сайт их не показывает.

## Нельзя

- Править или переименовывать оригиналы в `1_sources/` (кроме `inbox/`).
- Выдавать находку в интернете или чужое дерево за семейный источник.
